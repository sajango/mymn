# WAVE 5 EXIT SIGNALS

## Exit Overview

Wave 5 completion marks the **end of the impulse** - critical moment to exit long positions and potentially reverse to short.

## Wave 5 Characteristics

| Attribute | Typical Value | Signal Type |
|-----------|---------------|-------------|
| Length | 61.8% - 100% of Wave 1 | Completion zone |
| Volume | Lower than Wave 3 | Momentum fading |
| RSI | 60-70 with divergence | Key reversal signal |
| Extension | 100% - 161.8% max | Extended Wave 5 |

## Exit Trigger Conditions

**Primary EXIT signal when:**

1. **Fibonacci Extension Reached**
   - Price reaches 61.8% - 100% of Wave 1 from Wave 4
   - Extended: 100% - 161.8% possible
   - Beyond 161.8% rare (re-evaluate count)

2. **RSI Divergence Detected**
   - Price makes higher high
   - RSI makes **lower high** than Wave 3
   - Classic bearish divergence = HIGH confidence exit

3. **MACD Divergence**
   - Price higher than Wave 3 peak
   - MACD histogram **lower** than Wave 3 peak
   - Momentum exhaustion confirmed

4. **Volume Decline**
   - Volume at Wave 5 peak < Volume at Wave 3 peak
   - Participation decreasing
   - "Buying exhaustion" signal

## Extended Wave 5 Detection

When Wave 5 extends beyond normal limits:

| Condition | Implication |
|-----------|-------------|
| Wave 5 > 100% of W1 | Extended - expect deep correction |
| Wave 5 > 161.8% of W1 | Very extended - sharp reversal likely |
| Ending diagonal | Deep correction to Wave 4 territory expected |

**Trading Rule**: After extended Wave 5, expect correction to **at least** 50-61.8% of entire impulse.

## Ending Diagonal Detection

**Structure**: 5-wave pattern with overlapping waves

| Characteristic | Description |
|----------------|-------------|
| Overlap | Wave 4 enters Wave 1 territory |
| Shape | Wedge (converging trendlines) |
| Waves | All sub-waves are 3s (not 5s) |
| Signal | Strong reversal signal |

**Trading after Ending Diagonal**:
- Exit 100% of long position
- Aggressive SELL entry possible
- Target: Deep correction (50-78.6% retrace)

## Truncation Recognition

**Truncated Wave 5**: Fails to exceed Wave 3 high

| Condition | Action |
|-----------|--------|
| Price fails at Wave 3 level | Still valid Wave 5 |
| RSI divergence present | Confirms completion |
| Occurs after extended W3 | Expected behavior |

**Trading Rule**: Truncation still signals impulse complete - exit longs.

## Divergence Detection Guide

### RSI Divergence
```
Wave 3 Peak:
  Price: 3340 (highest so far)
  RSI: 78 (overbought)

Wave 5 Peak:
  Price: 3380 (new high)
  RSI: 65 (LOWER than W3)

Result: BEARISH DIVERGENCE
Action: High-confidence exit signal
```

### MACD Divergence
```
Wave 3 Peak:
  MACD Histogram: +15 (maximum)
  Signal Line: Bullish cross

Wave 5 Peak:
  MACD Histogram: +8 (LOWER peak)
  Signal Line: Still bullish but weakening

Result: MOMENTUM DIVERGENCE
Action: Exit signal confirmed
```

## Wave 5 Failure Modes

### Premature Exit Mistakes
1. **Exiting at W3**: Mistaking W3 for W5 due to strong momentum
2. **Missing extension**: Exiting too early when W5 extends
3. **Ignoring divergence**: Waiting for more despite clear signals

### Late Exit Mistakes
1. **Denial**: Hoping for more despite divergence
2. **Missed truncation**: Not recognizing W5 can fail to exceed W3
3. **Greed**: Holding for TP3 when signs show completion

## Wave B Trap Warning

After Wave 5 completes:
```
Wave A: Sharp drop (38.2% retrace)
Wave B: Bounce (looks like new impulse!)
        ↑ THIS IS A TRAP

Warning signs of Wave B (not new impulse):
- Only 3-wave structure (not 5)
- Volume lower than Wave 5
- RSI fails to reach overbought
- MACD stays weak
```

## Correction Trade After Wave 5

### Entry After Wave 5 (SELL)
1. Wait for Wave 5 completion confirmation
2. Enter SELL on first lower high
3. Stop: Above Wave 5 high + buffer
4. Target: 38.2-50% of entire impulse

### Re-Entry After Correction (BUY)
1. Wait for ABC or complex correction to complete
2. Look for Wave C completion signals (bullish divergence)
3. Enter BUY for new impulse
4. This is highest R:R trade (1:3+)
